# Streamliner Temporary Role Notes

This directory holds committed, temporary role handoff prompts for Streamliner
sessions. They are operational session-orientation assets, not design authority
and not permanent plugin skill definitions.

Use these notes when starting a focused Copilot session before the Streamliner
plugin has first-class skills or custom agents for these roles:

| Role note | Use when |
|---|---|
| [project-workstream-designer.md](project-workstream-designer.md) | Shaping ambiguous intent into candidate workstreams, boundaries, dependencies, and handoff briefs. |
| [workstream-creator.md](workstream-creator.md) | Turning one shaped candidate into executable workstream artifacts such as `brief.md`, `graph.json`, gates, checkpoints, and first-wave specs or issues. |

When equivalent plugin skills or agents exist, migrate the durable guidance into
those surfaces and remove or archive these temporary notes.
