Work Geometry Canvas Spike

Throwaway static mocks for comparing project-scoped multi-workstream visualization options.

These pages use the same mock Streamliner project: Documentation System, Session Launching, CLI / Distribution #40, Agent and Skill Context, Worker Hot Work, Multi-Workstream Dependencies, and Work Geometry Canvas. They intentionally optimize for ideation rather than production code.

Option A: Collapsed cards

A project overview where each workstream is a card and dotted lines connect imports to exports. This is the cleanest dashboard-like option and likely the easiest first slice.

Open cards view

Option B: Full mini-graphs

Each workstream expands into a small internal node graph on the same canvas. This makes exact connection points visible, but may get visually dense quickly.

Open mini-graphs view

Option C: Timeline lanes

A swimlane/timeline-style view focused on checkpoints, gates, imports, and exports over time. This is less graph-native but makes sequencing and availability easier to scan.

Open lanes view

Option D: Wave / checkpoint geometry

A heavier React Flow prototype where workstreams are wave tracks with checkpoint beads, then zoom into Streamliner-style wave containers with task cards.
