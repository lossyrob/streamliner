## Turn 10 — clouds: Q1/Q2 answers + concept-5 batch proposal (msg 116)
- **Q1 (does EVOI-rationing starve cross-case beliefs?) — no, if EVOI is defined right.** EVOI of a
  belief = per-invocation leverage × **invocation frequency**. A recurring low-stakes pattern has high
  *aggregate* EVOI via the frequency term; starvation only happens if you drop it. Buildable:
  **ration DEEP compilation, never RECURRENCE DETECTION** — run a cheap, **frame-independent counting
  pass** (cluster raw cases, flag frequency threshold); counting inherits no frame → production-
  independent for free; a flagged cluster earns deep distillation. "Recurrence is super-additive EVOI."
- **Q2 (does silver auditor promotion re-open folklore?) — real risk, two disciplines fix it.**
  A silent-default belief **suppresses its own falsifying signal** = unfalsifiable = folklore.
  (1) **No self-sealing:** promotion-auditor ≠ effect-auditor. (2) **THE SAMPLING OBLIGATION** (new):
  a silent-default belief must periodically **pay rent by deliberately surfacing** a fork it would have
  silenced, at a rate set by its half-life — **epsilon-greedy for the values layer** (silent-default =
  exploit, forced sampling = explore). Gold beliefs falsified by spontaneous builder reaction; silver
  beliefs must **manufacture** their own falsification. **Q2 and concept 5 are the SAME failure** —
  "stopped running the probe that would falsify me." One discipline, two surfaces.
- **Concept-5 batch proposal:** if an independent defeater-crafter per iteration is unaffordable,
  **batch it** — run repair-crafted defeaters within a budget, then gate the converged wave behind one
  independent defeater pass at wave altitude. Press it against the real budget.
